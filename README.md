# SkyGuru EMDR

Therapist tool for EMDR sessions. Single-file web app. Works two ways:

1. Standalone browser via Zoom screen-share (Phase 1).
2. Zoom App with Collaborate Mode, runs inside the Zoom client (Phase 2).

Live: https://emdr.phobia.aero

## Modes

- EMDR: bilateral eye movements, horizontal or diagonal, with optional bilateral clicks.
- Resource Installation: slow tempo, warm palette.
- Container: visualization with timer and a soft completion chime.
- Safe Place: calm landscape with gentle bilateral stimulation.

## Safety

- Speed hard-capped at 2 Hz.
- Audio is short bilateral clicks panned hard L/R synchronized with dot peak positions.
- Host has emergency stop, pause, and end-set controls in a floating sidebar that is not visible to the client when in Collaborate Mode.

## Distribution

Private. URL access only. Therapists share the link directly.
